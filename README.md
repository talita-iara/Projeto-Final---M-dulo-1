# Projeto Final Módulo 1 - Análise de Dados com Python - T4 SCTECH

Objetivo:

Projeto de análise de dados desenvolvido com Python, Pandas, SQL e PostgreSQL para organizar dados de vendas e gerar informações úteis para a tomada de decisão.

Armazenar os dados brutos no PostgreSQL.

Realizar consultas SQL e exportar os dados.

Tratar e transformar os dados com Pandas.

Analisar as vendas por filial, produto, pagamento e período.

Criar gráficos e métricas para responder às perguntas de negócio.


Tecnologias utilizadas:

Python

Pandas

Matplotlib

PostgreSQL

SQL

Git e GitHub


Estrutura do projeto

sql/: criação do banco, tabelas e consultas.

src/: leitura, transformação e análise dos dados.

data/raw/: dados originais e arquivos brutos.

data/processed/: base tratada e dicionário de dados.

resultados/: gráficos e resultados das análises.



Como executar

Instale o PostgreSQL e o Python.

Instale as bibliotecas descritas em requirements.txt.

Configure o banco de dados conforme as instruções do projeto.

Execute os scripts SQL na ordem indicada.

Execute os scripts Python na ordem indicada.




Fonte dos dados

Dataset Supermarket Sales, disponível no Kaggle: [www.kaggle.com/datasets/faresashraf1001/supermarket-sales](https://www.kaggle.com/datasets/faresashraf1001/supermarket-sales)


Resultados

Apresente as respostas às oito perguntas de negócio, acompanhadas de métricas e gráficos gerados a partir dos dados.
